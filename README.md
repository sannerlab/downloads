# Sanner Lab downloads

Installers, tutorial data and Python packages for the software of the
[Sanner Lab](https://sannerlab.github.io) at Scripps Research. The files are attached to the
[releases](https://github.com/sannerlab/downloads/releases) of this repository; each tool's
download page on the lab website links to them.

| Release | Contents |
|---|---|
| `adfrsuite-1.0` | ADFRsuite 1.0 installers (Linux, macOS, Windows): ADFR, AGFR, AutoSite, ADCP 1.0 |
| `adfrsuite-1.0-tutorials` | Data for the ADFR and AGFR tutorials |
| `autosite-tutorials` | Data for the AutoSite tutorial (1STP) |
| `adcp-1.0` | Data for the ADCP 1.0 tutorials, and `reduce` for Windows |
| `adcp-1.1` | ADCP 1.1 installation scripts (micromamba, conda) and example files |
| `adcp-pip-py37` | The Python 3.7 packages the ADCP 1.1 scripts install, served as a pip index at https://sannerlab.github.io/pip/py37/ |
| `adcp-papers` | ADCP preprint (2019) and its supporting information |
| `msms-2.6.1` | MSMS 2.6.1 for Linux, macOS, Windows and Arm64 |
| `mgltools-1.5.7` | MGLTools 1.5.7 installers and patched build, and the registration patch |
| `mgltools-1.5.6` | MGLTools 1.5.6 installers and patched build |
| `mgltools-tutorials` | PMV and Vision tutorials (PDF) for MGLTools 1.5.6 |

MSMS is free for academic use; commercial use needs a license (contact sanner@scripps.edu).
